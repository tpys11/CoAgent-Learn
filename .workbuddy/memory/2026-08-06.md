## Docker 前端不更新问题（commit c44be2a）
- 现象：start-coagent.bat（docker compose up -d）启动后界面仍是旧版
- 根因：compose 前端只挂载 `../frontend/src:/app/src`，tailwind.config.js（font-display/shadow-soft/圆角阶调）在 frontend 根目录，是镜像构建时的旧拷贝，Tailwind 不生成新工具类
- 修复：compose 增挂 tailwind.config.js、postcss.config.js、index.html 三个单文件，`docker compose up -d frontend` 重建容器后验证 curl 5173 已输出新代码
- 教训：以后改动 frontend 根目录配置（vite.config/tailwind/postcss/package.json）都必须重建或挂载；package.json 变更则需 `docker compose build frontend`
- 提示用户需硬刷新（Ctrl+Shift+R）清浏览器缓存
