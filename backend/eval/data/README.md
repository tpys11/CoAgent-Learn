# eval/data · 评测数据目录（官方提交要求）

## golden_qa.json — 黄金 QA 集（目标 ≥50 条）

- 种子源：`tests/golden_qa.json`（5 条，{q, expect:[关键词]}）——开箱即跑
- 扩容格式（本目录正式版）：
```json
{
  "question": "…",
  "expect_kps": ["知识点1", "知识点2"],
  "level_score": 0.8,
  "difficulty": 0.7,
  "sources": [{"title": "…", "url": "…"}],
  "answer": ""   // runner 跑链路后回填；人工审校字段
}
```
- 扩容路径：强模型从知识库切片批量草拟 QA + 知识点标注 → **人工每条 1-2 分钟审校** → 入库

## personas/ — 差异化画像组（官方要求 ≥2 组，建议 3 组）

每组一个 JSON：画像字段（selfLevel/target/用户背景/偏好…）+ 预期行为注记。
三组建议梯度：入门自学者(0.25) / 有基础进阶者(0.55) / 专业复习者(0.85)。
批量 runner（评估体系设计稿第三批）按 组×问题矩阵 自动跑全链并产出 IO 示例包。

## kb_slice/ — 垂直领域知识库切片（官方提交要求 ≥1）

放一份可复现的最小知识库（源文档 + 切片参数），保证评委可重放检索实验。
